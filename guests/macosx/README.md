# Mac OS X guests (PowerPC 10.0–10.5)

PowerPC Mac OS X on the shared `qemu-macos-ppc` launcher. Compose services:

- `macosx105` — 10.5.6 Leopard (`power_mac_g4_leopard`)
- `macosx104` — 10.4 Tiger (`power_mac_g4_tiger`)
- `macosx103` — 10.3 Panther
- `macosx102` — 10.2 Jaguar
- `macosx101` — 10.1 Puma (`-M mac99` without PMU)
- `macosx100` — 10.0 Cheetah (`-M mac99` without PMU)

Intel Snow Leopard is `guests/macosx-intel/`.
